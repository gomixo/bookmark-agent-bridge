# 采用临时 localhost WebSocket 桥接

扩展主动连接只监听 `127.0.0.1` 的临时 WebSocket 服务，Agent 通过 CLI 使用这条连接。该方案无需安装 Native Messaging Host 或保持 Windows 服务常驻，也比通过 CDP 操作内部页面稳定；代价是每次任务开始时需要用户提供本次会话的地址和令牌。

首次连接仍由用户点击触发。此后扩展通过 30 秒的定时唤醒在断线后自行重连，Chrome 挂起后台进程不再中断任务。自动重连有三个停止条件：用户主动断开（该状态被持久化）、服务主动关闭（扩展认为本次会话已结束）、连续 5 次连不上（扩展停止尝试并提示用户重新连接）。

Native Messaging 可在以后需要无人值守或企业安装时重新评估。CDP 没有受支持的书签域，只用于开发测试，不作为产品接口。
